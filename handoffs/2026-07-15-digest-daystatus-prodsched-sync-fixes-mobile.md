## Critical learnings (highest value)

- **The DBOS worker's production path had THREE independent latent bugs that masked each other.** In order of discovery: (1) **watermark** keyed on `production_shifts` (waste-advanced) skipped MC reports by date; (2) **extractor** hardcoded rows broke when the quarterly workbook shifted a row; (3) **mail-clerk manifest key** (`production_mc` emitted, `"production"` read) dropped MC's attachment entirely. #3 was the deepest — it had been there since the first commit and normally hid because a present waste report let the step "succeed" while MC came through empty. **The production-manager AGENT path (Python/IMAP, the sync-ictc skill) is a SEPARATE code path and works fine** — that's why every catch-up this session succeeded via the agent even while the worker was broken. When production data is stale, check the worker path specifically; don't assume the agent's success means the worker works.
- **"I ran a sync, why is it still awaiting?" is diagnosable from three tables.** `view_digest_operational_days` (op date), the per-stream `max(date)`, `ingestion_watermarks.last_run_at` (which employee ran when), and `sync_run_events` (what each report step actually did — `report_type='production'` with a lone `finalize: "Nothing new today"` = the manifest drop). On 07-15 the fetch log even showed "Found Daily Production Report … Downloaded 5 of 7" while production said "no report waiting" — proof the file was fetched but never routed.
- **Two different "off-by-one" bugs, both timezone/layout traps.** (1) SheetJS `cellDates:true` yields **local-midnight** `Date`s; reading them with `getUTC*` on a UTC+8 host shifts the calendar date back a day (the prod-schedule rest-days-on-Saturday bug — Renzo caught it, I was wrong to trust my own table over his sheet). Fix: decode the serial with `XLSX.SSF.parse_date_code` (no `Date`, no TZ). (2) The MC workbook's downtime/electricity/trucks sections shift row-position between quarterly templates — never hardcode rows; anchor on header-label text.
- **`shift_hrs` is the SCHEDULED shift length, not actual.** Actual productive hours = `shift_hrs − downtime`. Any "work hours" viz must subtract downtime, not add it.
- **The digest's day-status is the honest fix for `0`.** `resolveKpiDayStatus` (`lib/digest/day-status.ts`, pure) maps each KPI to `reported/awaiting/rest/stale/idle` from the day's plan (`production_schedule.shifts`) + `meta.streams` freshness. `rc_in` is `idle` when 0 (procurement, not shift-bound); `awaiting` = plan says run but stream silent; `stale` = stream lags op-date > 2 days. This is what makes an empty Production/Power card say "Awaiting report" instead of a scary `0`.
- **Joseph Go (kitz323@yahoo.com) is the boss; his emailed PRODUCTION SCHEDULE supersedes Renzo's PROD SCHED tab — on scheduling only, tonnages stay Renzo's.** His file is a quarterly plan-vs-actual tracker (one tab per quarter back to 2023); parse only the current+forward quarter, ignore his actual-tons columns and history. Merge tags `source='joseph:REV2'` vs `'gsheet:PROD SCHED'`. **The revision label is currently hardcoded `REV2`** — the data updates when he sends REV3 (latest-email-wins), but the tag won't say REV3 until we parse the subject.
- **`position:fixed` slide-overs break inside transformed/blurred ancestors.** The Open Blocks cards' `hover-lift` (transform) + `backdrop-blur` establish a containing block, trapping the panel in the widget. Portal to `document.body`. And the panel animates via a CSS transition on a permanently-mounted element (`isOpen = locKey !== null`) — conditional mount/unmount kills both slides; keep it mounted and toggle `locKey`.
- **Mobile could not be visually verified — `/` is behind Google auth.** The mobile pass is build-verified + reasoned; sheet heights (68–72dvh), WeekStrip card min-width, and 2-up KPI density are tuned by reason and want an on-device nudge. This is the first thing to review next session.
