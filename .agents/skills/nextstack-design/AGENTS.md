# nextstack-design

> **Note:** `CLAUDE.md` is a symlink to this file.

## Overview

Guides planning, design, and implementation of modern web apps using Next.js (App Router), TypeScript, shadcn/ui, and Supabase. Reach for this skill when architecting new features, designing UI components, writing data access patterns, or reviewing code quality. Enforces a minimalist, information-dense, utility-first aesthetic in the spirit of Notion/Raycast — structured, purposeful, never decorative for its own sake.

## Usage

Read `SKILL.md` for the complete skill instructions covering:
- Core stack (Next.js, TypeScript, shadcn/ui, Supabase, state management)
- Aesthetic philosophy (information density, minimalism with intent)
- Architecture patterns (App Router, Server Actions, TypeScript conventions, Supabase patterns)
- UI component patterns (dense data tables, sidebar navigation, forms, loading states, empty states)
- Planning checklist for new features
- Common pitfalls to avoid
- Tone and advisory guidance

## Key Topics

| Topic | Coverage |
|-------|----------|
| **Framework** | Next.js 14+ with App Router, Server Components by default |
| **Language** | TypeScript in strict mode, no `any` |
| **UI** | shadcn/ui primitives + Tailwind CSS, composition-first |
| **Backend** | Supabase (PostgreSQL), Row-Level Security always on |
| **State** | Zustand / React Context, minimal local UI state |
| **Aesthetic** | Notion / Raycast — structured, dense, purposeful |
